# Mini CRM Dashboard (Frontend)

This is a simple Mini CRM (Customer Relationship Management) web application built using HTML, CSS, and JavaScript.

The application allows users to manage client leads, track their status, and maintain follow-up notes without using any backend or database. All data is stored locally in the browser using localStorage.

---

##🔍 Features

* Add new leads (Name, Email, Source)
* View all leads in a dashboard layout
* Update lead status (New, Contacted, Converted)
* Add follow-up notes for each lead
* Dark mode toggle for better UI experience
* Responsive and clean card-based design
* Data persistence using browser localStorage

---

##🔨 Technologies Used

* HTML
* CSS
* JavaScript

---

## How It Works

* User enters lead details through the form
* Data is stored in localStorage
* Leads are displayed dynamically using JavaScript
* Status and notes can be updated anytime

---

## Use Case

This project simulates a basic CRM system used by freelancers, agencies, and startups to track potential clients and manage communication.
